# Navigation Flow

## Public website

- Landing page links to Courses, For Organisations, About Us, Contact, Login and Registration.
- Course catalogue links each course card to the Digital Foundations detail view.
- Course detail enrolment actions route to Login or Registration for the prototype.
- Contact and organisation enquiry forms show local demo confirmation states.

## Authentication

- Login includes a clearly labelled demo-role selector.
- Demo roles route to the corresponding learner, instructor, organisation, or platform dashboard.
- Registration offers learner registration and organisation enquiry routes.
- Forgot password displays a simulated local confirmation without claiming to send an email.

## Platform administration

- Admin dashboard links to organisation, user, content, translation, and certificate management.
- Organisation and user registers provide searchable demo tables.
- Content library links to the lesson editor.
- Translation management links to review content and records local review actions.
- Certificate registry presents demo completion records and does not claim national accreditation.
