# Component Catalog

The shared design system is split into reusable CSS layers:

- `design-tokens.css`: template-derived colours, spacing, radii, shadows and transitions.
- `reset.css`: browser normalisation only.
- `global.css`: body background, typography, links, focus states and brand text.
- `components.css`: buttons, icon containers, cards, forms, badges, progress bars, tables, tabs, modals and alerts.
- `layout.css`: header, navigation, page containers, sections, grids and composition helpers.
- `responsive.css`: tablet and mobile transformations.

Shared class conventions:

- `.btn`, `.btn-primary`, `.btn-secondary`, `.icon-btn`
- `.card`, `.card-yellow`, `.card-blue`
- `.form-field`, `.form-label`, `.form-control`, `.select-control`
- `.data-table` inside `.table-wrap`
- `.tabs` with `.tab`
- `.progress` with `.progress-value`
- `.modal-backdrop` with `.modal`
- `.badge`, `.alert`
- `.site-header`, `.site-nav`, `.header-actions`, `.page-main`, `.page-container`
